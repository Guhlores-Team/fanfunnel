## Left open (with reasons)

- **"To fulfil" drops a win as soon as it is Started.** The Today tile, the Fulfilment badge
  and "all clear" count only `pending`, so started-but-unfinished wins vanish from them (both the
  database and demo paths count `status = 'pending'`). Whether "in progress" should still count as
  waiting is a product decision for the owner; changing it touches the overview query, the demo
  store and alert semantics, so it was not changed here.
- **A definitive refusal on a fresh play shows the recovery buttons.** When `/api/spin` refuses
  (for example `no_prizes`), the fan sees "Check this spin before playing again" plus **Check this
  spin** / **Retry this same spin**. This is the deliberate durable-recovery contract (a refused
  POST keeps the saved request until the status check releases it), so it was left as is; fix 3
  removes the common way to reach it.
- **The server still serves an empty game** if a creator pins, schedules or activates one through
  the API, or empties a live game later. Refusing that in `set_fan_pass_game` / the live-game
  ranking needs a migration, which this branch may not add (0067 belongs to `gaps/b4-db`).
- **Keyboard focus is not returned if the fan is out of spins** after the win card closes (the
  play button stays disabled, so there is nothing usable to return to); focus stays on the page.
- **"Spin" wording on scratch/bingo fan pages** ("Spins left", "Powered by FanFunnel · every spin
  wins" footer, the welcome note sample). "Spin" is the credit unit across the product and the
  Terms ("Scratch tickets and bingo are other ways to use a spin"), so it was kept.
- **Demo `/c/<any slug>`** renders the demo creator (demo mode has one creator); the database path
  404s unknown slugs.
