## Stress-test plan

Run against the **TEST** project (`snmcrmhgevfqggxdiomu`) and a Preview, or a local `next start` pointing at TEST, never Production. Use k6 or autocannon for HTTP load, plus a Node harness on the service client that seeds fixtures and asserts invariants (reuse `scripts/db/*Probe.mjs` and `e2e/economic-fixtures.mjs`).

After **every** scenario, run these invariant checks:
